# Sistema de Temperatura Arduino

Aplicación de escritorio para Windows x64 con dos interfaces dentro de una sola ventana:

- **Temperatura:** panel original de temperatura con detección automática de puerto COM y canal analógico.
- **Temperatura y humedad:** panel AM2302/DHT22 con lectura de temperatura y humedad.

Selecciona el panel en el menú de inicio y usa **Menú principal** para volver. Cada proyecto mantiene su código Python, sketch de Arduino y archivo Excel por separado.

La página de descarga es GitHub Pages del repositorio. El instalador incluye Python y las dependencias y muestra progreso mientras instala. Se requiere Windows x64 y Microsoft Excel de escritorio para guardar datos. El Arduino debe tener cargado el sketch correspondiente; el instalador no reprograma la placa.
