Sistema de Temperatura Arduino

Una sola aplicación con dos interfaces: temperatura, o temperatura y humedad. Cada panel conserva sus lecturas y su registro.

Descargar para Windows

Instalador para Windows de 64 bits

Instalación

  1. Descarga y ejecuta el instalador. Verás el progreso de instalación y la app avisará cuando esté lista.
  2. Elige Temperatura o Temperatura y humedad desde el menú.
  3. Usa Menú principal para volver y cambiar de panel dentro de la misma ventana.
  4. Conecta el Arduino por USB. Cada proyecto tiene su propio código Python y sketch de Arduino.
  5. La app busca automáticamente el puerto COM y los canales analógicos. Cada panel registra sus datos en su propio archivo Excel.

Requisitos

  • Windows de 64 bits.
  • Microsoft Excel de escritorio para registrar datos.
  • Arduino con el sketch del proyecto elegido cargado.

La app incluye por separado los dos sketches. El instalador no programa la placa.
