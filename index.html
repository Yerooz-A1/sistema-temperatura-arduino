Instalador para Windows de 64 bits

Instalación

  1. Descarga y ejecuta el instalador.
  2. Conecta el Arduino por USB.
  3. Abre “Sistema de Temperatura”; detectará el puerto COM y canal automáticamente.

Requisitos

  • Windows de 64 bits.
  • Microsoft Excel de escritorio.
  • Arduino con el sketch incluido ya cargado.

El instalador no cambia ni programa el firmware del Arduino.
